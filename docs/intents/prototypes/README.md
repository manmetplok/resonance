# Prototypes with work left

Self-contained HTML design prototypes (open `index.html` directly; some
folders also have a `DESIGN.md` and screenshots) whose feature is only
partly built, or not built. Each row names what is still missing compared
with the prototype and the intent(s) that carry that remainder. When an
intent finishes a prototype's remainder, move the folder to
[`../../history/prototypes/`](../../history/prototypes/README.md) and add it
to that README.
